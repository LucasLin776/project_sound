## 处理耗时

完整录音第一次运行：窗口推理约 3.44 秒，SED 推理约 0.81 秒，入口内部总耗时约 29.64 秒。

再次运行：窗口推理约 7.87 秒，SED 推理约 2.02 秒，入口内部总耗时约 18.89 秒。

总耗时包含模型加载、音频解码/重采样、首次库初始化、结果压缩和绘图，不包含 Python 启动及顶层模块导入。两次运行受首次初始化及本机其他负载影响，不构成吞吐量或延迟承诺。实际服务器应以常驻加载模型的工作进程测量吞吐量、排队耗时和报警延迟；目前提供的是本地命令行入口。

## 录音质量与任务边界

原始录音：44.1 kHz、单声道、16 位 PCM、30.002721 秒。数字满幅采样点占比约 1.5889%，已在结果中标记削波告警。

这些模型仅识别通用 AudioSet 声音类别。实际输出中出现音乐、车辆、枪声等标签也不能当作真实场景的语义结论，更不能替代螺栓检测。当前没有螺栓专用训练数据划分、分类器或已校准报警阈值，没有评估螺栓事件的准确率、召回率、误报率。
